# Batch status service

Each numbered section is an independent endpoint. The requirements apply only to successful requests. Authentication, transport failures and deployment are outside this document.

## REQ-001: Status endpoint 1
An authenticated operator sends GET /status/1. The endpoint returns HTTP 200 with JSON {"endpoint": 1, "state": "ready"}.

**Acceptance criteria**
- Given an authenticated operator, when GET /status/1 completes successfully, then HTTP 200 is returned and the JSON equals {"endpoint": 1, "state": "ready"}.
